# Home Automation System - Lab 02

## Voraussetzungen
- Java 17+
- Gradle 8+
- Node.js 18+ (für Frontend)

## Home Automation System starten
./gradlew run

## Externes Order-Processor System starten (separates Terminal)
./gradlew runOrderProcessor

## Frontend starten
cd frontend && npm install && npm run dev

## Web-Interface
- Frontend: http://localhost:3000
- Backend API: http://localhost:8084
